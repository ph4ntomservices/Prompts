# CIRCUIT FLOW — PROMPT UNIVERSAL DE IMPLEMENTAÇÃO

Atue como um desenvolvedor frontend sênior, especialista em JavaScript, CSS, SVG, Canvas e animações interativas.

Sua missão é implementar o **CIRCUIT FLOW** diretamente no projeto atual, criando uma experiência visual inspirada em circuitos eletrônicos que conectam os elementos reais da interface.

## 1. CONCEITO PRINCIPAL

O Circuit Flow é um sistema visual que transforma os componentes de um site em uma rede eletrônica interconectada.

Linhas luminosas percorrem a interface, conectando cards, botões, menus, imagens e seções. Pulsos de energia percorrem essas conexões, criando a sensação de que toda a página funciona como um circuito digital.

O efeito deve acompanhar a estrutura real do site.

**Não crie apenas linhas aleatórias no fundo.** O sistema deve identificar os elementos existentes e construir conexões visualmente coerentes entre eles.

## 2. ANÁLISE DA IDENTIDADE VISUAL — PRIORIDADE MÁXIMA

Antes de implementar, analise cuidadosamente o design do projeto.

O Circuit Flow deverá seguir a identidade visual original do site, sem impor uma aparência genérica.

Identifique automaticamente:

- Cor principal do projeto.
- Cores secundárias.
- Cor de destaque (accent).
- Cores dos botões.
- Cores dos elementos interativos.
- Gradientes utilizados.
- Variáveis CSS.
- Paleta do tema claro ou escuro.
- Cores predominantes dos componentes.

### Adaptação automática

Utilize as cores identificadas para definir:

- Cor das trilhas eletrônicas.
- Cor dos pulsos luminosos.
- Cor dos pontos de conexão.
- Cor dos nós.
- Cor dos efeitos de ativação.
- Intensidade e tonalidade dos brilhos.

Exemplos:

- Projeto roxo: circuitos em tonalidades de roxo, com pulsos complementares.
- Projeto azul: circuitos azuis com variações compatíveis.
- Projeto verde: circuitos verdes e tonalidades secundárias.
- Projeto vermelho: circuitos vermelhos e cores complementares.
- Projeto monocromático: circuitos em branco, cinza e preto.

Esses exemplos não são cores obrigatórias. A implementação deve identificar as cores reais do projeto.

### Regras obrigatórias

- Não utilize uma paleta fixa para todos os sites.
- Não imponha roxo ou azul como cores padrão.
- Não altere a identidade visual original.
- Evite cores que não combinem com o projeto.
- Garanta contraste suficiente.
- Mantenha harmonia entre trilhas e pulsos.
- Atualize as cores quando o tema mudar.
- Disponibilize personalização manual como alternativa.

## 3. IDENTIFICAÇÃO DOS ELEMENTOS

Analise automaticamente a estrutura da página e identifique:

- Cards.
- Botões.
- Containers.
- Menus.
- Navegação.
- Títulos.
- Imagens.
- Seções.
- Formulários.
- Componentes interativos.

Utilize as posições reais dos elementos para construir as conexões.

O sistema deve considerar a hierarquia da interface e evitar conexões desnecessárias.

## 4. CONSTRUÇÃO DOS CIRCUITOS

Implemente:

- Trilhas horizontais e verticais.
- Ramificações eletrônicas.
- Nós de conexão.
- Pontos luminosos.
- Pulsos de energia.
- Cruzamentos organizados.
- Conexões entre componentes.
- Animações de ativação.

As trilhas devem apresentar uma aparência semelhante a circuitos eletrônicos reais, priorizando ângulos retos e trajetos organizados.

## 5. ANIMAÇÃO DOS PULSOS

Os pulsos luminosos devem percorrer as trilhas de maneira contínua e fluida.

Funcionamento esperado:

1. Uma trilha é identificada ou criada.
2. Um pulso luminoso aparece em seu início.
3. O pulso percorre o caminho.
4. Ao alcançar um nó, pode ativar uma ramificação.
5. Ao chegar ao componente conectado, destaca-o brevemente.
6. O pulso desaparece ou continua sua trajetória.

Evite movimentos aleatórios, velocidades exageradas e excesso de brilho.

## 6. COMPORTAMENTO DURANTE A NAVEGAÇÃO

O Circuit Flow deve acompanhar a rolagem da página.

- Identifique novas seções quando entrarem na área visível.
- Atualize as conexões conforme necessário.
- Evite desenhar circuitos em elementos que ainda não estão disponíveis.
- Preserve conexões estáveis durante a navegação.
- Recalcule posições após redimensionamentos.
- Considere mudanças dinâmicas no conteúdo.

O efeito deve funcionar tanto em páginas curtas quanto em páginas longas.

## 7. PERSONALIZAÇÃO

Disponibilize configurações para:

| Opção | Descrição |
|---|---|
| Auto Colors | Identificação automática das cores do projeto. |
| Manual Colors | Personalização manual das cores. |
| Circuit Speed | Velocidade dos pulsos. |
| Glow Intensity | Intensidade do brilho. |
| Circuit Thickness | Espessura das trilhas. |
| Connection Density | Quantidade de conexões. |
| Pulse Frequency | Frequência dos pulsos. |
| Animation Mode | Modo automático ou controlado. |
| Section Activation | Ativação por seção. |
| Visual Intensity | Modo discreto ou intenso. |
| Enable/Disable | Ativação e desativação do efeito. |

O modo de cores automáticas deve estar ativado por padrão.

## 8. INTEGRAÇÃO UNIVERSAL

Antes de programar:

1. Analise a arquitetura do projeto.
2. Identifique o framework utilizado.
3. Examine a estrutura HTML e os componentes.
4. Verifique os estilos existentes.
5. Identifique possíveis conflitos.

Implemente o Circuit Flow como um módulo independente, adaptando-o à estrutura encontrada.

Requisitos:

- Não imponha frameworks.
- Não substitua componentes existentes.
- Não altere o conteúdo original.
- Não adicione dependências desnecessárias.
- Evite modificações extensas no HTML.
- Preserve a identidade visual e as funcionalidades.

Utilize SVG ou Canvas quando forem apropriados para desenhar e animar os circuitos.

## 9. DESEMPENHO E RESPONSIVIDADE

- Utilize requestAnimationFrame quando apropriado.
- Evite cálculos contínuos desnecessários.
- Utilize IntersectionObserver quando necessário.
- Otimize os eventos de scroll e resize.
- Evite listeners duplicados.
- Não bloqueie cliques ou interações.
- Adapte o efeito para dispositivos móveis.
- Respeite prefers-reduced-motion.
- Evite consumo excessivo de CPU e memória.

## 10. RESULTADO VISUAL ESPERADO

O resultado deve transmitir a sensação de que o site possui uma infraestrutura eletrônica ativa.

Os circuitos devem:

- Combinar com as cores reais do projeto.
- Conectar elementos da interface.
- Apresentar pulsos luminosos fluidos.
- Acompanhar a navegação.
- Respeitar o layout.
- Ter aparência profissional e organizada.

O efeito deve complementar o design, nunca competir com ele.
